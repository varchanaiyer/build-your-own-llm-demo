2 · Tokenization

Computers don't understand letters — they understand numbers. We break text into tokens (here, single characters) and map each one to an id using a vocabulary.

"hello" → ['h','e','l','l','o'] → [3, 2, 4, 4, 5]

3 · Embeddings

An id like 5 doesn't capture meaning. So each token becomes a vector — a list of numbers that places it in "meaning space." Words with similar meanings end up close together.

Below: tiny 4-number embeddings for five words. We compute cosine similarity — values near 1.0 mean "very similar."

4 · The Attention Mechanism

"The animal didn't cross the street because it was too tired." What does "it" refer to? Attention lets each word look back and decide which other words matter.

For each word the model asks: Query (what am I looking for?), Key (what do I contain?), Value (what info do I give?). The scores below show what the word "sat" pays attention to, after a softmax turns them into probabilities.
